## Como trabalho
1. **Descoberta** — workshop com gestores e atendentes: jornadas, gargalos, regras de negócio e metas.
2. **Desenho** — persona, mapa de intenções, fluxos e critérios de transbordo.
3. **Protótipo** — diálogos de exemplo validados com o cliente antes de configurar.
4. **Implantação** — agente de IA, base de conhecimento, integrações via API e canais.
5. **Evolução** — métricas de experiência e curadoria contínua.
